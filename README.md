# 漢字クラフト6年生・ステージ2 実験版 β1

## これは実験用の別アプリです
現在お子さんが使用中の「6年生アプリ」と、完成した「1026アプリ」は変更しません。実験版はローカル保存キー `kanji-craft-6-beta-stage2-v1` を使うので、既存アプリの学習履歴には触れません。正式版への学習記録の移行機能は、現段階ではありません。

## ステージ
- ステージ1：現行6年生アプリの30字。漢字と出題ヒントは現行版に合わせました。通常30問。
- ステージ2：前ステージと重複しない新出30字。異なる読み方に対応した47問＋ステージ1からの復習20問＝通常67問。
- 復習20問はステージ1の正答状況から選びます。まだ記録がなければ固定の20字を使用します。
- 読み方別の成績を記録し、苦手チャレンジの問題文選択に反映します。
- 部品・選択肢・字形は「1026アプリ Ver.3.8」のデータをベースにしています。

## ボス
ステージ2では通常問題を20問クリアするごとに新ボスが出現します。1)シールド、2)反撃、3)二字熟語の1文字目、4)二字熟語の2文字目、の4手が1回のボス戦です。時間は4手通算です。ボス戦の正解数はお小遣いの分母・分子に含めません。

## おこづかい
通常問題の「各問題への初回回答の正答率×100円」を10円単位で四捨五入します。誤答後の再出題で正解しても初回正答率は増えません。同日の通常報酬は最高額との差額だけを週間台帳に加算します。苦手チャレンジの報酬は別枠です。日曜21時（日本時間）締切です。

## GitHub Pagesへの公開
1. GitHub で **新しいパブリックリポジトリ** `kanji-craft-6-beta` を作ります（現行版のリポジトリとは分けます）。
2. このZIPに入っている `index.html` と `apple-touch-icon.png` を、リポジトリのトップ階層へアップロードします。
3. Settings > Pages > Build and deployment > Deploy from a branch を選び、`main` / `/ (root)` を指定して保存します。
4. 公開ページは、ユーザー名が `natsuya0815` の場合、設定が有効になった後 `https://natsuya0815.github.io/kanji-craft-6-beta/` になる構成です。実際の公開状況はGitHubのPages画面で確認してください。
5. ブラウザのキャッシュが古い場合はSafariを再読み込みしてください。

`index.html`にステージ1・2の書字練習PDFは組み込んであるため、PDFファイルの別アップロードは不要です。

### 注意
このβ版は学習実験用です。元の30字を保持していますが、基盤エンジンは1026アプリのため、旧6年生アプリと見た目・一部進行ルールが異なります。問題文やボスの難易度はプレイ後に調整できます。
